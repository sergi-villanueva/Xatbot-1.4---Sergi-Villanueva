# Com contribuir al projecte

Gràcies per considerar contribuir al **XatBot Talent 2026**!

## Codi de Conducta

Aquest projecte segueix el [Codi de Conducta de Contributor Covenant](https://www.contributor-covenant.org/). Esperem que tots els participants el respectin.

## Com contribuir

1. **Fes un Fork** del repositori
2. **Crea una branca** per la teva feature (`git checkout -b feature/nova-funcionalitat`)
3. **Fes els canvis** i comprova que funcionen
4. **Fes commit** amb missatges clars (`git commit -m 'Add nova funcionalitat'`)
5. **Push** a la teva branca (`git push origin feature/nova-funcionalitat`)
6. Obre una **Pull Request**

## Tipus de contribucions benvingudes

- Millores al widget HTML/CSS
- Millores en el scraping
- Millores en prompts del Gemini
- Correcció d'errors
- Documentació
- Noves funcionalitats
